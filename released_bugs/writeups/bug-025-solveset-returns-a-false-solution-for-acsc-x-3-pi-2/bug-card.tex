\section*{Bug 25: \texttt{solveset} returns a false solution for \texttt{acsc(x) = 3*pi/2}}

\begin{counterexamplebox}
\textbf{Task.} Solve the inverse cosecant equation over the complex domain.
\[
\operatorname{acsc}(x)=\frac{3\pi}{2}
\]

\medskip
\textbf{SymPy's answer.}
\[
\operatorname{solveset}\!\left(\operatorname{acsc}(x)=\frac{3\pi}{2},x,\mathbb{C}\right)=\{-1\}.
\]

\medskip
\textbf{Correct answer.}
\[
\emptyset
\]

\medskip
\textbf{Explanation.} Substitution gives \(\operatorname{acsc}(-1)=-\pi/2\), so the returned value has residual \(-2\pi\). The target \(3\pi/2\) is coterminal with \(-\pi/2\) for the periodic cosecant function, but it is outside the principal range of \(\operatorname{acsc}\).

\medskip
\textbf{Likely root cause.} The diagnosis locates the bad step in \(\texttt{\_invert\_complex}\), where \(\operatorname{acsc}(x)=y\) is inverted mechanically as \(x=\csc(y)\) via \(\texttt{acsc.inverse()}\), without checking that \(y\) is in the principal \(\operatorname{acsc}\) image. This is a new instance of a known failure mode.

\medskip
\textbf{Artifact (GitHub).} \bugbundle{bug-025-solveset-returns-a-false-solution-for-acsc-x-3-pi-2}
\end{counterexamplebox}
