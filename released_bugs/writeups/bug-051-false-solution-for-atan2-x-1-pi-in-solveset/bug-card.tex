\section*{Bug 51: False solution for atan2(x, 1) = pi in solveset}

\begin{counterexamplebox}
\textbf{Task.} Solve the real equation
\[
\operatorname{atan2}(x,1)=\pi.
\]

\medskip
\textbf{SymPy's answer.}
\[
\operatorname{solveset}(\operatorname{atan2}(x,1)=\pi,\ x,\mathbb{R})=\{0\}.
\]

\medskip
\textbf{Correct answer.}
\[
\emptyset.
\]

\medskip
\textbf{Explanation.} Substituting the returned value gives
\(\operatorname{atan2}(0,1)=0\), not \(\pi\). Since the second argument is
positive, \(\operatorname{atan2}(x,1)=\arctan(x)\), whose real principal range
is \((-\pi/2,\pi/2)\).

\medskip
\textbf{Likely root cause.} The diagnosis traces the false positive to
\SymPy's generic \texttt{\_invert\_real} path in \texttt{solveset}: after
\(\operatorname{atan2}(x,1)\) simplifies to \(\arctan(x)\), it applies
\(\tan\) to the out-of-range right-hand side \(\pi\) without enforcing
\(\arctan\)'s range. This is a new instance of a known failure mode.

\medskip
\textbf{Artifact (GitHub).} \bugbundle{bug-051-false-solution-for-atan2-x-1-pi-in-solveset}
\end{counterexamplebox}
