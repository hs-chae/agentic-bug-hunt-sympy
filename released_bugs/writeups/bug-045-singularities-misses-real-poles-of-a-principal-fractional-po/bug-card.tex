\section*{Bug 45: singularities misses real poles of a principal fractional-power denominator}

\begin{counterexamplebox}
\textbf{Task.} Find the real singularities of the reciprocal expression.
\[
  \frac{1}{(x^2)^{1/3}-1}
\]

\medskip
\textbf{SymPy's answer.}
\[
  \operatorname{singularities}\!\left(\frac{1}{(x^2)^{1/3}-1},\ x,\ \mathbb{R}\right)=\varnothing.
\]

\medskip
\textbf{Correct answer.}
\[
  \{-1,1\}
\]

\medskip
\textbf{Explanation.} For real \(x\), \(x^2\ge 0\), so
\((x^2)^{1/3}=1\) exactly when \(x^2=1\). Substituting \(x=1\) or
\(x=-1\) makes the denominator zero, so both points are real poles.

\medskip
\textbf{Likely root cause.} The diagnosis traces the failure through
\texttt{singularities} into \texttt{solveset}: the real-domain rewrite produces
an absolute-value equation, and \texttt{\_invert\_abs} rejects the whole finite
target set \(\{-1,1\}\) because one branch is negative, discarding the valid
\(\operatorname{Abs}(x)=1\) branch too. This is a new instance of a known failure
mode.

\medskip

\end{counterexamplebox}
