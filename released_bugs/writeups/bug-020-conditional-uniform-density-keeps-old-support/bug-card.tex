\section*{Bug 20: conditional uniform density keeps old support}

\begin{counterexamplebox}
\textbf{Task.} Compute the density of a uniform random variable conditioned on
being larger than \(1/2\).
\[
Y=\operatorname{given}(U,U>1/2),\qquad U\sim\operatorname{Uniform}(0,1).
\]

\medskip
\textbf{SymPy's answer.} \[
\operatorname{density}(Y)(x)
=2\cdot\mathbf{1}_{[0,1]}(x).
\]

\medskip
\textbf{Correct answer.} \[
\operatorname{density}(Y)(x)
=2\cdot\mathbf{1}_{(1/2,1]}(x).
\]

\medskip
\textbf{Explanation.} Conditioning on \(U>1/2\) must both divide by
\(P(U>1/2)=1/2\) and restrict the support to \((1/2,1]\). Note that SymPy's returned
density has total mass 2.

\medskip
\textbf{Likely root cause.} The diagnosis identifies
\texttt{ContinuousPSpace.conditional\_space} in \nolinkurl{sympy/stats/crv.py}
as storing only the renormalized original PDF, while
\texttt{compute\_density} returns it unchanged when no variables are
marginalized.  This is a new failure mode with no public precedent.

\medskip
\textbf{Artifact (GitHub).} \bugbundle{bug-020-conditional-uniform-density-keeps-old-support}
\end{counterexamplebox}
