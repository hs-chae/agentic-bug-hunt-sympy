\section*{Bug 57: singularities misses the logarithmic singularity of Chi(x) at zero}

\begin{counterexamplebox}
\textbf{Task.} Find the complex singularities of the hyperbolic cosine integral.
\[
\operatorname{singularities}(\operatorname{Chi}(x),x,\mathbb{C})
\]

\medskip
\textbf{SymPy's answer.}
\[
\operatorname{singularities}(\operatorname{Chi}(x),x,\mathbb{C})=\emptyset .
\]

\medskip
\textbf{Correct answer.} The singularity set must contain \(0\); for this
minimal input, the expected set is \(\{0\}\).

\medskip
\textbf{Explanation.} Near the origin,
\(\operatorname{Chi}(x)=\gamma+\log(x)+\) analytic terms, so \(x=0\) is a
logarithmic singularity. SymPy also evaluates \(\operatorname{Chi}(0)\) to
\(\texttt{zoo}\), and the recorded right-hand limit is \(-\infty\), so an empty
singularity set is not mathematically equivalent.

\medskip
\textbf{Likely root cause.} The diagnosis identifies
\nolinkurl{sympy/calculus/singularities.py} as using a syntactic scan for
negative powers, explicit logarithms, and a few inverse hyperbolic atoms; it
does not consult \(\operatorname{Chi}\)'s zero value or leading-term hook in the
special-function implementation. This is a new instance of a known failure mode.

\medskip

\end{counterexamplebox}
