\section*{Bug 26: solveset returns a false solution for acot(x) = -pi/2}

\begin{counterexamplebox}
\textbf{Task.} Solve the real inverse-cotangent equation.
\[
  \operatorname{acot}(x)=-\frac{\pi}{2},\qquad x\in\mathbb{R}.
\]

\medskip
\textbf{SymPy's answer.}
\[
  \operatorname{solveset}(\operatorname{acot}(x)=-\pi/2,x,\mathbb{R})=\{0\}.
\]

\medskip
\textbf{Correct answer.}
\[
  \varnothing.
\]

\medskip
\textbf{Explanation.} Substituting SymPy's returned point gives
\(\operatorname{acot}(0)=\pi/2\), so the residual for
\(\operatorname{acot}(x)+\pi/2=0\) is \(\pi\). The value \(-\pi/2\) is outside
SymPy's principal real range for \(\operatorname{acot}\), recorded as
\((-\pi/2,\pi/2]\).

\medskip
\textbf{Likely root cause.} The diagnosis identifies
\nolinkurl{sympy/solvers/solveset.py}'s generic real inversion path applying
\texttt{acot.inverse()}, namely \(\cot\), to \(-\pi/2\) without checking the
principal branch range. This is a new instance of a known failure mode.

\medskip
\textbf{Artifact (GitHub).} \bugbundle{bug-026-solveset-returns-a-false-solution-for-acot-x-pi-2}
\end{counterexamplebox}
