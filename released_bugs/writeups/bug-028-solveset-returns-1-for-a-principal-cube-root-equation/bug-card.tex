\section*{Bug 28: solveset returns -1 for a principal cube-root equation}

\begin{counterexamplebox}
\textbf{Task.} Solve the principal cube-root equation over the real numbers.
\[
x^{1/3}=-1
\]

\medskip
\textbf{SymPy's answer.}
\[
\operatorname{solveset}(\operatorname{Eq}(x^{1/3},-1),x,\mathbb{R})=\{-1\}.
\]

\medskip
\textbf{Correct answer.}
\[
\varnothing
\]

\medskip
\textbf{Explanation.} Substituting SymPy's returned value gives
\((-1)^{1/3}+1\ne0\).  SymPy's \(x^{1/3}\) is a principal complex power, so
\((-1)^{1/3}=\exp(i\pi/3)=1/2+\sqrt{3}i/2\), not the real cube root \(-1\).

\medskip
\textbf{Likely root cause.} In \nolinkurl{sympy/solvers/solveset.py},
\texttt{\_invert\_real} handles odd-denominator rational powers using
\texttt{real\_root} semantics, and the later domain check verifies definedness
rather than equation truth.  The deduplication assessment frames this as a new
instance of a known failure mode.

\medskip
\textbf{Artifact (GitHub).} \bugbundle{bug-028-solveset-returns-1-for-a-principal-cube-root-equation}
\end{counterexamplebox}
