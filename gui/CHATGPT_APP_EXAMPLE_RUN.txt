1. Locate an already-open gui checkout or clone a fresh one from:
   https://github.com/hs-chae/agentic-bug-hunt-sympy.git

   Native Windows PowerShell:
   $RepoUrl = "https://github.com/hs-chae/agentic-bug-hunt-sympy.git"
   $RepoName = "agentic-bug-hunt-sympy"
   $CurrentBranch = ""
   if (Test-Path ".\.git") {
       $CurrentBranch = git branch --show-current
   }
   if ((Test-Path ".\.git") -and (Test-Path ".\gui\CHATGPT_APP_EXAMPLE_RUN.txt") -and ($CurrentBranch -eq "gui")) {
       $RepoDir = (Get-Location).Path
   } else {
       $ParentDir = (Get-Location).Path
       $RepoDir = [IO.Path]::GetFullPath((Join-Path $ParentDir $RepoName))
       if (Test-Path $RepoDir) {
           $Stamp = Get-Date -Format "yyyyMMdd-HHmmss"
           $RepoDir = [IO.Path]::GetFullPath((Join-Path $ParentDir "$RepoName-$Stamp"))
       }
       git -c core.longpaths=true clone --branch gui --single-branch $RepoUrl $RepoDir
       if ($LASTEXITCODE -ne 0) { throw "Repository clone failed; verify private GitHub authentication" }
   }
   Set-Location $RepoDir

   macOS/Linux:
   REPO_URL="https://github.com/hs-chae/agentic-bug-hunt-sympy.git"
   REPO_NAME="agentic-bug-hunt-sympy"
   if test -d .git && test -f gui/CHATGPT_APP_EXAMPLE_RUN.txt && test "$(git branch --show-current)" = "gui"; then
       REPO_DIR="$(pwd -P)"
   else
       PARENT_DIR="$(pwd -P)"
       REPO_DIR="$PARENT_DIR/$REPO_NAME"
       if test -e "$REPO_DIR"; then
           REPO_DIR="$PARENT_DIR/$REPO_NAME-$(date +%Y%m%d-%H%M%S)"
       fi
       git clone --branch gui --single-branch "$REPO_URL" "$REPO_DIR"
   fi
   cd "$REPO_DIR"

   e. If validation returns needs_repair or ok false, repair only that phase's output and retry until it passes.
